# Research — annotate

Dated notes that informed this app's decisions, one file per topic:
`YYYY-MM-DD-<topic>.md`. Each note separates **verified** claims (source URL or
measurement, with version and date — the repo habit: measure, don't trust docs)
from **unverified** ones, flagged as such. A note here is the evidence a
`../decisions.md` entry points at, kept so a future reader can re-derive why this
app is the way it is.
